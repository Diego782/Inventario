# Product Overview

**InvenPro** is a Spanish-language inventory and sales management system (Sistema de Inventario y Ventas) built as a single-page web application.

## Core Modules

- **Dashboard** – Overview stats and key metrics
- **Inventario** – Product inventory with stock tracking, SKU management, and status alerts (En Stock / Bajo Stock / Crítico)
- **Ventas** – Sales management
- **Fiadores** – Guarantor/co-signer management
- **Empleados** – Employee management
- **Horarios** – Schedule/shift management
- **Configuración** – App settings

## Target Users

Business administrators managing inventory, sales, and staff. The UI and all user-facing text is in **Spanish**.

## Key Characteristics

- All UI labels, button text, column headers, and status values are in Spanish
- Navigation is section-based (single page, no routing between sections)
- Supports light/dark theme via `next-themes`
- Deployed on Vercel (Vercel Analytics included)
