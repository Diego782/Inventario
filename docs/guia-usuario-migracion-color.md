# Guía del Usuario: Migración de Color Personalizado

## ¿Qué cambió en Dego?

Hemos mejorado cómo se guarda el color personalizado de tu organización. Ahora tu color se guarda en la nube, lo que significa:

✅ **Tu color persiste en todos tus dispositivos**: verás el mismo color en tu computadora, tablet y teléfono.

✅ **Cada organización tiene su propio color**: si perteneces a varias organizaciones, cada una mantiene su identidad visual única.

✅ **La pantalla de inicio de sesión es siempre neutra**: nunca verás el color de una organización antes de iniciar sesión (más profesional y seguro).

✅ **Sin interferencias**: el color de una organización no se mezcla con el de otra.

## ¿Qué es la Migración Automática?

Si ya tenías un color personalizado guardado en tu navegador, Dego te lo ofrecerá aplicar a tu organización **automáticamente** la primera vez que la selecciones.

### ¿Cómo funciona?

1. **Inicias sesión** y seleccionas tu organización.
2. **Aparece un mensaje** en la esquina inferior derecha que dice:
   ```
   Color heredado detectado
   Se detectó un color personalizado guardado localmente.
   ¿Deseas aplicarlo a esta organización?
   
   [Aplicar]
   ```
3. **Tienes 10 segundos** para decidir.
4. Si haces clic en **"Aplicar"**:
   - Tu color se guarda en la nube.
   - Se aplica inmediatamente a tu organización.
   - La copia local se elimina (ya no se necesita).
5. **Si no haces clic** o cierras el mensaje:
   - Tu organización usará el color por defecto de Dego (paleta negra neutral).
   - Puedes cambiar el color manualmente cuando quieras.

### ¿Qué pasa si el proceso falla?

Si por alguna razón la migración no puede completarse (por ejemplo, sin conexión a internet):

- **Tu color local se conserva intacto**: no se pierde ningún dato.
- **Aparecerá un mensaje de error**: "No se pudo completar la migración del color. Inténtalo de nuevo."
- **Puedes intentarlo de nuevo** más tarde recargando la página o volviendo a seleccionar tu organización.

## Preguntas Frecuentes

### ¿Tengo que hacer algo?

**No necesariamente**. Si ya tenías un color personalizado:

- **Si aceptas la migración**: tu color se guarda automáticamente en la nube. Listo.
- **Si no aceptas**: tu organización usa el color por defecto. Puedes cambiarlo manualmente cuando quieras desde la configuración.

### ¿Dónde cambio el color manualmente?

1. Inicia sesión en Dego.
2. Selecciona tu organización.
3. Ve a **Configuración** en el menú lateral.
4. Busca la sección **Identidad Visual** o **Color de Tema**.
5. Elige tu color preferido.
6. Los cambios se guardan automáticamente en la nube.

### ¿Puedo revertir el color migrado?

Sí, en cualquier momento. Simplemente ve a la configuración de tu organización y cambia el color a otro. El cambio se guarda automáticamente.

### ¿La migración afecta mi preferencia de modo claro/oscuro?

**No**. Tu preferencia de modo claro/oscuro (tema del navegador) es completamente independiente del color de la organización. La migración **solo** afecta el color primario (azul, verde, rojo, etc.), no el modo claro/oscuro.

### ¿Qué pasa si pertenezco a varias organizaciones?

La migración se ofrece **independientemente para cada organización**. Si tenías un color local guardado:

- La **primera organización** que selecciones (y que no tenga color guardado) recibirá la oferta de migración.
- Si aceptas, el color se guarda en esa organización.
- Las **demás organizaciones** no verán la oferta (el color local ya se habrá migrado o eliminado).
- Cada organización puede tener su propio color personalizado.

### ¿Esto es un cambio obligatorio?

La migración del **sistema** sí es obligatoria (ahora todos los colores se guardan en la nube). Pero **aceptar la oferta de migración automática** es opcional: si no la aceptas, simplemente configuras el color manualmente desde el menú de configuración.

### ¿Cuántas veces aparece el mensaje de migración?

**Una sola vez** por organización en cada sesión del navegador. Si cierras el mensaje o recargas la página, puede volver a aparecer. Una vez que aceptes la migración o que tu organización tenga un color guardado en la nube, el mensaje **no volverá a aparecer**.

### ¿Qué pasa con mis datos?

- **Tus datos están seguros**: la migración solo afecta el color de la interfaz, no tus productos, ventas, empleados u otros datos de negocio.
- **No se pierde información**: si la migración falla, tu color local se conserva intacto.
- **Privacidad garantizada**: cada organización tiene su propio color, completamente aislado de las demás.

## Ventajas del Nuevo Sistema

| Antes (localStorage) | Ahora (Base de Datos) |
|---|---|
| Color local al navegador | Color en la nube (todos tus dispositivos) |
| Un solo color para todas las organizaciones | Color único por organización |
| El color se filtraba al login | Login siempre con paleta Dego (profesional) |
| Se perdía al cambiar de navegador | Persiste en todos los navegadores |

## ¿Necesitas Ayuda?

Si tienes problemas con la migración o el cambio de color:

1. **Verifica tu conexión a internet**: la migración requiere conexión para guardar en la nube.
2. **Recarga la página**: a veces soluciona problemas temporales.
3. **Intenta cambiar el color manualmente** desde la configuración.
4. **Contacta al soporte técnico** si el problema persiste.
